Rork is a cross‑platform AI‑powered app builder that enables creators to design, develop, and launch mobile (iOS, Android) and web applications without writing code. Leveraging generative AI, Rork automates UI design, backend integration, and publishing, allowing businesses to bring tools, social apps, and games to the App Store and Google Play within hours. The platform offers a visual editor, pre‑built components, and one‑click deployment, positioning Rork as a fast, no‑code solution for modern app development.

**Areas:** Company · AI · AppBuilder · NoCode · Mobile · Web

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Rork: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
